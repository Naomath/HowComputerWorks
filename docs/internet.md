## インターネット概論
### はじめに
Wikipediaを引用すると、「インターネット（英: the Internet）は、 TCP/IPプロトコルを用いて接続された世界規模のコンピュータネットワークである。」と出てきます。
ここで用語を整理すると、TCP/IPプロトコルとは接続の規格のことで、コンピュータネットワークとは複数のコンピューターが接続されたシステムを言います。
家庭のルーターを起点としてネットーワークや、会社や病院内のネットワークもコンピューターネットワークであり、それらがインターネットと繋がっています。
「インターネットに接続する」、といえばChromeなどのブラウザを思い浮かべますが、全世界をまたがるコンピューターネットワークに参画する、というイメーｊで、それらのネットワークに参加する何百億台のコンピューターと相互通信できるようになる、と考えたほうがいいと思います。

インターネットを勉強するときのポイントとして、以下の2点を気に留めながら考えると良いかと思います。
- 現実の郵便システムのアナロジーを考える
- 日頃のインターネットの仕組み(Youtubeやメールなど)を思い浮かべ、それらを実現するためには何が必要かを考える

### パケット交換
インターネットでの通信はパケット交換で行われます。
パケット交換では、送信するデータをパケットに分割し、そのパケットに宛先のアドレスを紐付けて、送信されます。
対比するものとしては、回線交換があり、これは電話などで用いられている方式で、通信端末同士で回線を独占して、情報を送り合う方式です。
パケット交換は、回線を独占せずに、同一回線にいくつもの行先へのパケットが流れることになります。

災害時に、「普通の電話よりもLINE電話のほうが繋がりやすい」などと言われることがありますが、これは前者が回線交換、後者がパケット交換であるからです。
回線交換では、限られた回線の数しかないため、それらが全て使用されているとつながることができませんが、一方でパケット交換ではそのようなことがないので、通話の品質（遅延など）はともかくとして、つながりやすいということです。
一応、インターネットも通信という電話や無線やらの文脈の延長線上にあるため、このような回線交換と比べられることもあるわけです。

### インターネットでの識別子
インターネットでの識別子といえば、IPアドレスが有名かと思います。
IPアドレスは規格としてIPv4とIPv6があるのですが、現在のインターネットで使われているのはIPv4のほうなので、そちらの解説をします。
IPv4ではアドレスは32bitで表されます。
$2^32=4294967296$で約43億個のアドレスがありますが、おそらく足りないのでは、と思われるでしょう。
実際に足りないため、IPv6は128bitで構成され、約340澗個のアドレスがあります。
ただし、現在ほとんどIPv4が使われているのは、プライベートIPアドレス、というものが技術がその不足分を補っているからです。

まずは、自身のコンピューターのIPアドレスを以下のコマンドで調べてみましょう。
```bash 
ip -4 addr
```
これで自身のLinuxのIPv4のネットワークで割り振られている番号がわかります。
``127.0.0.1``というのは自分自身を指定する特別のIPアドレスになります。
他のアドレスとして何があるかはよく見ましょう。

グローバルIPアドレスは限られており、一意に定める必要があるので、適切に割り当てる必要があります。
全世界で管理している団体がIANAという団体であり、アジアの管理団体APNICがアジア地域の管轄をIANAから依頼され、JPNICが日本での管轄をAPNICから依頼されているという形式になっています。
JPNICはアドレスを割り当てるわけですが、アドレス一つ一つを割り当てるというよりは、どこからどこまでのアドレス範囲、アドレス空間を割り当てるといいます。
[このサイト](https://ipv4.fetus.jp/jp?_lang=ja-JP)から日本に割り当てられているアドレス空間を確認できます。
余談ですが、パケットにはどのIPアドレスから来たかの送信元アドレスがついているので、送信元アドレスと上記のようなサイトを照らし合わせれば、どこからその通信がやってきたのか（例えば、サイバー攻撃もパケットなのでどこからきたかを分析するのは大事）がわかります。

例えば、``1.0.16.0/20``がJPNICには割り振られていますが、この意味はIPアドレスが``1.0.16.0 - 1.0.31.255``の範囲で使えるということです。
````1.0.16.0/20``を32bitで表すと、``00000001 00000000 00010000 00000000``になりますが、これの上位20bit分は指定で、残りの``32-20=12``分は自由に使えるよ、ということです。
ですので、自由に変えられるビットを``X``で表すと、``00000001 00000000 0001XXXX XXXXXXXX``というように表すことができます。
JPNICはさらにこのアドレス空間をたとえば、``1.0.20.0/23``=``00000001 00000000 0001010X XXXXXXXX``というように分けて配っています。
